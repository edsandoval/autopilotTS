Configuration

i The root directory path where your project repositories are stored. This is the parent folder containing your git repositories.
i The directory path where Autopilot stores ticket data and configuration files. Leave empty to use the current directory.
i The default git branch to use as the base for creating new branches when working on tickets. Typically 'develop' or 'main'.
i The GitHub Copilot AI model to use for code generation and assistance. Different models may have different capabilities and performance.
i The language to use for generating ticket resolution reports and status messages in the terminal output.
i Custom prompt template for ticket command execution. Use ${FILE} placeholder to reference the ticket file location.
i Custom prompt template for AI-powered ticket resolution. Use ${ID}, ${DESCRIPTION}, and ${TYPE} placeholders to inject ticket details and type-specific instructions.
i Enable verbose logging and detailed debug output for troubleshooting. Shows detailed Copilot SDK requests/responses.
i Use for bug-fix tickets: ask the agent to find root cause, apply a minimal focused fix, and include a short analysis in the report. Use ${ID} and ${DESCRIPTION} where needed.
i Use for enhancements: extend or improve existing functionality while keeping backward compatibility; include approach and changed files in the report.
i Use for new features: identify integration points, implement incrementally and document how the feature integrates with existing modules.
i Use for code review tasks: analyze code for bugs, style, security and performance; propose fixes and list suggested changes in the report.
i Use for refactors: improve code structure and readability without changing behavior; include motivation and files refactored in the report.
i When enabled, Autopilot will inspect the system clipboard for images when opening the New Ticket modal and attempt to extract ticket data using Copilot CLI.
i Custom prompt used to extract ticket fields from clipboard images. Use $IMAGE_FILE to reference the temporary image file path.
